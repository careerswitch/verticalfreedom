# HealthFest — Workshops to Create (copy-paste sheet)

Source: `Program terapeuti Healthfest.xlsx` → 17 group workshops, 26–28 June 2026.
Phase 1 = group workshops only. The "Sesiuni individuale" (1-on-1) rows are **deferred** and not listed here.

> **Romanian descriptions below are neutral starting drafts** generated from each workshop's title/type — they make no specific therapeutic or medical claims. **Have each presenter review/approve (and adjust) their own description before publishing.**

## How to enter each one
1. **Workshops → Add New Workshop.**
2. **Title** → paste the title below.
3. **Description** (the main editor body) → paste the Romanian description.
4. **Workshop Details** sidebar → fill **Seat limit**, **Presenter / Therapist**, **Start**, **End**, **Location** from the block.
5. **Publish.**
6. To add the English version: in the **Languages** box, click the **＋** under the UK flag and translate the **Title** + **Description**. *Seat limit / Start / End / Location carry over — the seat limit field is read-only on the English copy by design.*

> All 17 appear on one page via the single **`[healthfest_registration]`** shortcode, auto-grouped by day with their times — no per-workshop code needed.
